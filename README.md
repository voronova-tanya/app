# Book Catalog API

веб-сервис для управления каталогом книг с рекомендательной системой, построенный на FastAPI.

##  О проекте

Book Catalog API - это  backend-сервис, который позволяет:
- Управлять каталогом книг (CRUD операции)
- Работать с авторами и категориями
- Аутентифицировать пользователей с помощью JWT токенов
- Оценивать книги и получать рекомендации на основе алгоритмов машинного обучения
- Получать топ книг с использованием Wilson score

## Основные возможности

### CRUD операции
- **Книги**: создание, чтение, обновление, удаление
- **Авторы**: управление авторами книг
- **Категории**: организация книг по жанрам и темам
- Связи между таблицами: книги-категории, авторы-книги, пользователи-книги.

### Аутентификация и авторизация
- Регистрация новых пользователей
- JWT токены для безопасного доступа
- Защищенные эндпоинты (требуют авторизации)
- Разграничение прав доступа (владелец может редактировать свои книги)

### Бизнес-логика
- **Алгоритм расчета рейтинга книг** (Байесовское среднее)
- **Рекомендательная система** (похожие книги на основе категорий, рейтинга, года выпуска)
- **Ранжирование топ книг** (Wilson score с доверительным интервалом)
- Автоматические рекомендации на основе оценок

### Технические особенности
- Автоматическая документация API (Swagger UI, ReDoc)
- Валидация данных через Pydantic
- Асинхронная обработка запросов
- Пагинация списков
- Полное покрытие тестами

## Технологии

- **FastAPI** - современный веб-фреймворк
- **SQLAlchemy** - ORM для работы с БД
- **SQLite** - реляционная база данных (легко заменяется на PostgreSQL)
- **python-jose** - JWT токены
- **passlib** - хеширование паролей
- **pytest** - тестирование
- **Uvicorn** - ASGI сервер
